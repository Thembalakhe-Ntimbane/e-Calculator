# e-Calculator

A simple and clean calculator app for everyday arithmetic and quick calculations.

## Overview

e-Calculator is a lightweight calculator project designed to be easy to use, efficient, and friendly for daily tasks. It keeps the interface minimal while supporting the core operations users expect from a standard calculator.

## Features

- Addition, subtraction, multiplication, and division
- Clear and straightforward user interface
- Lightweight design for fast use
- Suitable for everyday calculation needs

## Purpose

This project was created to provide a straightforward calculator experience with a clean, modern layout and easy-to-understand functionality.

## Getting Started

Open the app and begin using the calculator immediately. The project is intended to be simple, stable, and easy to extend if more functions are needed in the future.
